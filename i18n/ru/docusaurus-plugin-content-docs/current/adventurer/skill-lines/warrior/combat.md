# <img src="/icons/skills/combat/icon.png" alt="Combat" className="icon-svg" /> Бой

Эта особая ветка навыков отражает врождённые боевые способности [персонажа](/docs/glossary/adventurer). Она отличается от остальных веток тем, что содержит только 1 тип кубиков навыков. Кубики боя можно бросать в любом боевом режиме, кроме «Магии» ([<img src="/icons/magic.svg" alt="Magic Icon" className="icon-svg" />](/docs/battles/battle-forms/magic)), а в режиме «Оборона» ([<img src="/icons/defensive.svg" alt="Defensive Icon" className="icon-svg" />](/docs/battles/battle-forms/defensive)) — использовать для предотвращения урона.

Если способность добавляет [свободные](/docs/glossary/free) кубики боя, используйте кубики боя врагов вместо кубиков навыка «Бой». Они не учитываются в лимите кубиков, заданном вашими характеристиками [«Выносливость»](/docs/adventurer/stats/stamina) или [«Магия»](/docs/adventurer/stats/magicka), но для других эффектов, например способностей предметов типа [<img src="/icons/weapon.svg" alt="Weapon Icon" className="icon-svg" />](/docs/adventurer/items/types/weapon), считаются кубиками боя.

Саму ветку навыков «Бой» утратить нельзя. Кубики этой ветки можно утратить в [фазе наград](/docs/campaign/day/reward-phase).

Кубики навыка «Бой» служат для нанесения урона или защиты. Значение их результатов зависит от текущего [боевого режима](/docs/battles/battle-forms/index/). Эти кубики можно бросать в любом режиме, кроме [<img src="/icons/magic.svg" alt="Magic Icon" className="icon-svg" />](/docs/battles/battle-forms/magic).
