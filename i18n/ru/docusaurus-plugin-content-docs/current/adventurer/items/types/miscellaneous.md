# <img src="/icons/miscellaneous.svg" alt="Miscellaneous Icon" /> Разное

Предметы подтипа «Разное» обладают разнообразными способностями, не использующими механики других подтипов. Каждая способность предмета <img src="/icons/miscellaneous.svg" alt="Miscellaneous Icon" className="icon-svg" /> применяется согласно своему описанию.
