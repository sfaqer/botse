# <img src="/icons/clothing.svg" alt="Clothing Icon" /> Одежда {#clothing}

Предметы одежды дают дополнительные возможности. Каждый предмет <img src="/icons/clothing.svg" alt="Clothing Icon" className="icon-svg"/> добавляет [способность класса](/docs/battles/adventurer-turn/class-ability). Способности класса можно применять действием во время боя, потратив [стойкость](/docs/glossary/tenacity).
