Каждый [ход](/docs/glossary/turn), когда этой [боевой единице](/docs/glossary/unit) впервые наносит урон [соседняя](/docs/glossary/adjacent) боевая единица-противник, эта боевая единица наносит # урона в ответ, если она не была [повержена](/docs/glossary/defeated).

---

:::info
<!-- translate:on -->
**Если враг с «Ответным ударом» получает второй экземпляр навыка «Ответный удар», складываются ли значения «Ответного удара»?**

У врага может быть только один экземпляр каждого навыка. Если он должен получить более одного экземпляра номерного навыка и значения различаются, используется навык с наибольшим значением.
