Когда эта [боевая единица](/docs/glossary/unit) определяет цель, [бросьте 1 D6](/docs/glossary/roll-a-d6). Если результат больше или равен текущему количеству ОЗ цели, эта цель сбрасывает не-[<img src="/icons/consumable.svg" alt="Consumable Icon" className="icon-svg" />](/docs/adventurer/items/types/consumable) [предмет](/docs/adventurer/items/index) из ячейки активного снаряжения.

**Как взаимодействуют «Оглушение» и «Кража»?**

Эффект состояния [«Оглушение»](/docs/battles/status-effects/daze) гласит, что если враг передвигается в свой ход, он не может бросать кубики в этот ход. Для применения «Кражи» требуется бросить кубик, поэтому оглушённый враг, который передвинулся, не может использовать свой навык «Кража».
