В конце [хода](/docs/glossary/turn) этой [боевой единицы](/docs/glossary/unit) разместите верхнюю боевую единицу из стопки [поверженных](/docs/glossary/defeated) в [ближайшей](/docs/glossary/closest) [незанятой](/docs/glossary/occupied) клетке к этой боевой единице с [<img src="/icons/party-size.svg" alt="Party Size Icon" className="icon-svg" />](/docs/glossary/party-size) ОЗ. Этот новый враг не совершает ход в этом [раунде](/docs/battles/battle-round).
