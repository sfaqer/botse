Когда эта [боевая единица](/docs/glossary/unit) выбирает цель, её цель должна истощить определённое количество кубиков из своих [ячеек активности](/docs/glossary/active-slot) в зависимости от текущей погоды.

- Солнечная погода = 1
- Дождь = 2
- Наводнение = 3.
