Кульминационный этап каждого задания гильдии приводит к боевой встрече. Для этого боя лимит вражеских сил рассчитывается по значению ОО-цели, заданному выбранным уровнем сложности, а не по счётчику ОО отряда. Чтобы найти верное значение ЛВС, найдите в таблице ниже раздел, соответствующий эпизоду вашей кампании; затем выберите строку своего уровня сложности и столбец по количеству игроков. Значение ОО сложности, на котором основано каждое значение ЛВС, указано под ним в скобках.

| Уровень сложности | 1 игрок    | 2 игрока   | 3 игрока   | 4 игрока   |
| ----------------- | ---------- | ---------- | ---------- | ---------- |
| Ученики           | 13 (13 ОО) | 26 (13 ОО) | 42 (14 ОО) | 56 (14 ОО) |
| Адепты            | 16 (16 ОО) | 32 (16 ОО) | 48 (16 ОО) | 64 (16 ОО) |
| Эксперты          | 18 (18 ОО) | 36 (18 ОО) | 54 (18 ОО) | 72 (18 ОО) |
