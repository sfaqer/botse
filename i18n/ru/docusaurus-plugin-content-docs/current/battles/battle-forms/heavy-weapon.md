**[Дальность](/docs/glossary/range):** только соседние клетки.

Этот режим представляет атаки ближнего боя с использованием навыков владения двуручным оружием, например ветки [«Двуручное оружие»](/docs/adventurer/skill-lines/warrior/two-handed).
