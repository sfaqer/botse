Символы боевых режимов встречаются в ветках навыков, описаниях способностей и на предметах типа [«Оружие»](/docs/adventurer/items/types/weapon). Во время действия [атаки](/docs/battles/adventurer-turn/engage) боевой режим [персонажа](/docs/glossary/adventurer) ограничивает, какие кубики можно бросить вместе, и определяет его [дальность](/docs/glossary/range).

| Символ                                                          | Название                                                        | Дальность                                                                                  | Описание                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <img src="/icons/defensive.svg" alt="Defensive Icon" />         | [Оборона](/docs/battles/battle-forms/defensive)                 | Не применяется.                                                                            | Этот режим позволяет использовать навык [«Бой»](/docs/adventurer/skill-lines/warrior/combat) для предотвращения урона вместо его нанесения или подготавливать другие защитные навыки, например [«Тяжёлую броню»](/docs/adventurer/skill-lines/warrior/heavy-armor).             |
| <img src="/icons/heavy-weapon.svg" alt="Heavy Weapon Icon" />   | [Тяжёлое оружие](/docs/battles/battle-forms/heavy-weapon)       | Только соседние клетки.                                                                    | Этот режим представляет атаки ближнего боя с использованием навыков владения двуручным оружием, например ветки [«Двуручное оружие»](/docs/adventurer/skill-lines/warrior/two-handed).                                                                                           |
| <img src="/icons/light-weapon.svg" alt="Light Weapon Icon" />   | [Лёгкое оружие](/docs/battles/battle-forms/light-weapon)        | Только соседние клетки.                                                                    | Этот режим представляет атаки ближнего боя с использованием навыков владения одноручным оружием, например ветки [«Одноручное оружие и щит»](/docs/adventurer/skill-lines/warrior/one-hand-and-shield).                                                                          |
| <img src="/icons/magic.svg" alt="Magic Icon" />                 | [Магия](/docs/battles/battle-forms/magic)                       | В пределах значения [магии](/docs/adventurer/stats/magicka).                               | Этот режим представляет атаки с использованием магии, например ветки навыков [«Посох разрушения»](/docs/adventurer/skill-lines/mage/destruction-staff). В этом режиме кубики [боя](/docs/adventurer/skill-lines/warrior/combat) нельзя собирать для броска.                     |
| <img src="/icons/ranged-weapon.svg" alt="Ranged Weapon Icon" /> | [Дальнобойное оружие](/docs/battles/battle-forms/ranged-weapon) | В пределах значения [выносливости](/docs/adventurer/stats/stamina), кроме соседних клеток. | Этот режим представляет атаки на расстоянии с использованием таких навыков, как «Лук». В этом режиме нельзя выбирать целью [боевые единицы](/docs/glossary/unit) в [соседних](/docs/glossary/adjacent) клетках, но [дальность](/docs/glossary/range) считается обычным образом. |
