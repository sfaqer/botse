| Символ                                              | Название                                           | Описание                                                                                                                                                                                                                                               |
| --------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <img src="/icons/bane.svg" alt="Bane Icon" />       | [Проклятие](/docs/battles/status-effects/bane)     | Эта боевая единица получает 1 единицу [неблокируемого урона](/docs/glossary/true-damage) в начале каждого своего хода.                                                                                                                                 |
| <img src="/icons/blind.svg" alt="Blind Icon" />     | [Слепота](/docs/battles/status-effects/blind)      | Эта боевая единица считает все боевые единицы противниками. Если она атакует, целью может быть только [сильнейшая](/docs/glossary/strongest) [соседняя](/docs/glossary/adjacent) боевая единица.                                                       |
| <img src="/icons/daze.svg" alt="Daze Icon" />       | [Ошеломление](/docs/battles/status-effects/daze)   | Эта боевая единица не может бросать кубики в тот же ход, в который она передвигалась, и не может передвигаться в тот же ход, в который бросала кубики. В конце хода этой боевой единицы уберите этот кубик.                                            |
| <img src="/icons/fear.svg" alt="Fear Icon" />       | [Страх](/docs/battles/status-effects/fear)         | Эффекты навыков этой боевой единицы, не относящихся к «Бою», игнорируются. Этот эффект не применяется к кубикам навыков, уже находящимся в [ячейках активности](/docs/glossary/active-slot) или на [треке перезарядки](/docs/glossary/cooldown-track). |
| <img src="/icons/maim.svg" alt="Maim Icon" />       | [Увечье](/docs/battles/status-effects/maim)        | Когда эта боевая единица бросает кубики боя, общий выпавший урон делится пополам, а затем округляется вниз. Этот эффект не влияет на [неблокируемый урон](/docs/glossary/true-damage).                                                                 |
| <img src="/icons/stealth.svg" alt="Stealth Icon" /> | [Скрытность](/docs/battles/status-effects/stealth) | Эту боевую единицу могут выбирать целью только противники, которые находились в [соседних с ней клетках](/docs/glossary/adjacent) в начале текущего хода. После того как эта боевая единица нанесёт урон, уберите этот кубик.                          |
