| Гильдия                                                     | Городское действие павильона гильдии                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Круг чемпионов](/docs/campaign/guilds/circle-of-champions) | **Battlemaster:** просмотрите колоду обычных предметов <img src="/icons/common-item.svg" alt="Common Item Icon" className="icon-svg" /> и получите первый попавшийся предмет типа «Оружие» ([<img src="/icons/weapon.svg" alt="Weapon Icon" className="icon-svg" />](/docs/adventurer/items/types/weapon)) или «Доспех» ([<img src="/icons/armor.svg" alt="Armor Icon" className="icon-svg" />](/docs/adventurer/items/types/armor)). Затем перемешайте колоду.                                                                                                |
| [Тёмное Братство](/docs/campaign/guilds/dark-brotherhood)   | **Mark of the Black Hand:** поместите кубик состояния [«Страх»](/docs/battles/status-effects/fear) (<img src="/icons/fear.svg" alt="Fear Icon" className="icon-svg" />) в ячейку активного снаряжения как [предмет](/docs/adventurer/items/index). В свой [ход](/docs/glossary/turn) в бою вы можете использовать этот предмет, чтобы применить кубик состояния [«Страх»](/docs/battles/status-effects/fear) (<img src="/icons/fear.svg" alt="Fear Icon" className="icon-svg" />) к [соседнему](/docs/glossary/adjacent) [врагу](/docs/glossary/enemy).        |
| [Глаза королевы](/docs/campaign/guilds/eyes-of-the-queen)   | **Reconnoiter:** посмотрите 2 верхние карты колоды мирных (<img src="/icons/peaceful.svg" alt="Peaceful Icon" className="icon-svg" />) или конфликтных (<img src="/icons/conflict.svg" alt="Conflict Icon" className="icon-svg" />) встреч в провинции. В любом порядке положите каждую карту либо наверх, либо под низ колоды.                                                                                                                                                                                                                                |
| [Гильдия бойцов](/docs/campaign/guilds/fighters-guild)      | **Guild Hall Sparring:** потратьте 1 сохранённое [ОО](/docs/glossary/xp), чтобы освоить любую ветку навыков Воина ([<img src="/icons/warrior.svg" alt="Warrior Icon" className="icon-svg" />](/docs/adventurer/skill-lines/warrior)) из мешочка наставника.                                                                                                                                                                                                                                                                                                    |
| [Гильдия магов](/docs/campaign/guilds/mages-guild)          | **Guild Hall Study:** [сбросьте](/docs/glossary/discard) 1 [предмет](/docs/adventurer/items/index) типа «Зелье» ([<img src="/icons/potion.svg" alt="Potion Icon" className="icon-svg" />](/docs/adventurer/items/types/potion)) или «Зачарование» ([<img src="/icons/enchantment.svg" alt="Enchantment Item Icon" className="icon-svg" />](/docs/adventurer/items/types/enchantment)), чтобы освоить любую ветку навыков Мага ([<img src="/icons/mage.svg" alt="Mage Icon" className="icon-svg" />](/docs/adventurer/skill-lines/mage)) из мешочка наставника. |
| [Внешний Дозор](/docs/campaign/guilds/outer-watch)          | **Community Outreach:** [сбросьте](/docs/glossary/discard) 1 [предмет](/docs/adventurer/items/index) типа «Расходник» ([<img src="/icons/consumable.svg" alt="Consumable Icon" className="icon-svg" />](/docs/adventurer/items/types/consumable)) или «Одежда» ([<img src="/icons/clothing.svg" alt="Clothing Icon" className="icon-svg" />](/docs/adventurer/items/types/clothing)), чтобы получить 3 пункта [стойкости](/docs/glossary/tenacity).                                                                                                            |
| [Орден Псиджиков](/docs/campaign/guilds/psijic-order)       | **The Old Ways:** утратьте кубик навыка Мага ([<img src="/icons/mage.svg" alt="Mage Icon" className="icon-svg" />](/docs/adventurer/skill-lines/mage)) 1-го уровня, чтобы освоить кубик навыка Мага ([<img src="/icons/mage.svg" alt="Mage Icon" className="icon-svg" />](/docs/adventurer/skill-lines/mage)) 2-го уровня из той же ветки.                                                                                                                                                                                                                     |
| [Гильдия воров](/docs/campaign/guilds/thieves-guild)        | **Scoundrels:** [сбросьте](/docs/glossary/discard) 1 обычный предмет <img src="/icons/common-item.svg" alt="Common Item Icon" className="icon-svg" />, чтобы освоить любую ветку навыков Вора ([<img src="/icons/thief.svg" alt="Thief Icon" className="icon-svg" />](/docs/adventurer/skill-lines/thief)) из мешочка наставника.                                                                                                                                                                                                                              |
| [Неустрашимые](/docs/campaign/guilds/undaunted)             | **Pledged:** [сбросьте](/docs/glossary/discard) все [предметы](/docs/adventurer/items/index) в магазине и пополните его новыми предметами в соответствии со значениями магазина. Затем получите 1 предмет из нового набора.                                                                                                                                                                                                                                                                                                                                    |
