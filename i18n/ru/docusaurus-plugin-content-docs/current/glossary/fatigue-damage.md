# <img src="/icons/fatigue.svg" alt="Fatigue Icon" /> Урон от усталости

В начале каждого раунда усталости каждый [персонаж](/docs/glossary/adventurer) получает 1 кубик [переутомления](/docs/glossary/fatigue). Затем каждый персонаж получает [неблокируемый урон](/docs/glossary/true-damage), равный общему количеству кубиков переутомления на его [треке перезарядки](/docs/glossary/cooldown-track).
